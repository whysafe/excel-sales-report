# Автоматический Excel-отчёт о продажах

Скрипт превращает CSV-выгрузку из CRM в оформленный Excel-отчёт с графиками и живыми формулами. Типичная задача «автоматизировать отчёт, который менеджер собирает руками каждый понедельник».

## Возможности

- **Сводка**: выручка, число продаж, средний чек, товаров продано; таблица по месяцам с планом и процентом выполнения; столбчатая диаграмма «выручка против плана» и круговая диаграмма долей категорий
- **Менеджеры**: продажи, выручка, средний чек, план и процент выполнения; гистограммы в ячейках и красная или зелёная подсветка
- **Товары**: рейтинг товаров по выручке, количество и доля в общей выручке
- **Данные**: исходные строки с формулой суммы, автофильтром и закреплённой шапкой
- Формулы в Excel живые: если поправить строку на листе «Данные» или план, проценты пересчитаются
- План выручки в месяц задаётся аргументом
- Ошибочная строка в CSV приводит к понятному сообщению с номером строки
- Флаг `--demo` генерирует пример выгрузки за текущий год и строит по нему отчёт

## Стек

Python 3.10+, openpyxl (диаграммы, условное форматирование, формулы), pytest.

## Как запустить

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python report.py --demo                                        # output/demo_sales.csv и output/report.xlsx
python report.py sales.csv --plan 3000000 --out output/report.xlsx
python -m pytest -v
```

| Аргумент | Что делает |
|---|---|
| `csv` | путь к выгрузке продаж |
| `--demo` | создать пример данных в `output/demo_sales.csv` и построить отчёт по нему |
| `--plan X` | план выручки в месяц, по умолчанию 2 500 000 |
| `--out путь` | куда сохранить отчёт, по умолчанию `output/report.xlsx` |

Тесты запускаются в GitHub Actions (`.github/workflows/tests.yml`) на Python 3.11 и 3.12.

## Настройка

Формат входного CSV: разделитель `;`, кодировка UTF-8 (с BOM или без), дата в виде ГГГГ-ММ-ДД, цена может быть с запятой.

```
date;manager;category;product;qty;price
2026-03-14;Иванова А.;Ноутбуки;Ноутбук 14;1;89000
```

В отчёт попадает год последней даты в файле. План менеджера считается как месячный план, умноженный на число прошедших месяцев и поделённый на число менеджеров.

## Как это устроено

- Проценты выполнения, средний чек и суммы строк записываются формулами (`=B9/C9`, `=C2/B2`, `=E2*F2`), а не готовыми числами.
- Условное форматирование: `CellIsRule` подсвечивает выполнение ниже 90% и от 100%, `DataBarRule` рисует гистограммы выручки по менеджерам.
- Диаграммы строятся через `openpyxl.chart` по ссылкам на диапазоны таблицы, поэтому обновляются вместе с данными.
- Пример данных генерируется `random.Random(seed)`, так что при одном и том же дне запуска получается одинаковый файл.
- Денежный формат `#,##0 "₽"` и формат даты `DD.MM.YYYY` задаются ячейкам, а не превращают числа в текст.
